How it works

1

If they were stuck at the same spot, one tap says so. The tile gets darker. The count is the proof you were never alone.

3

Their dashboard ranks doubts by count, so the next lecture starts where this one lost people.

Why it works

Psychologists call it pluralistic ignorance: each student privately assumes everyone else understood, so the question stays unasked. Anonymity removes the cost of asking. The Me too count removes the illusion that you were the only one.
